# Rocky SDK 1.0.2 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the pre-release vendored Rocky Wallet SDK with official `@rocky-wallet/dapp-sdk@1.0.2` and adopt capability-gated, `asset_id`-based asset handling.

**Architecture:** Keep Rocky isolated on `/rocky/`. The hook owns SDK availability, connection, account, catalog, balance, and transfer state; pure asset helpers join catalog and balance data by exact `asset_id`; the page only renders hook state and initiates explicit user actions.

**Tech Stack:** React 19, TypeScript 5.7, Vite 6, Yarn 1, Vitest, `@rocky-wallet/dapp-sdk@1.0.2`.

## Global Constraints

- Require Rocky Wallet Extension 1.0.2 or later.
- Never join or select configured assets by display symbol; use exact `asset_id`.
- Preserve the legacy positional transfer path only when no dynamic catalog is available.
- Keep all Rocky provider calls scoped to the `/rocky/` page.
- Do not rely on account or connection events because Extension 1.0.2 does not dispatch them.
